# CPalius CMF 2.2.4

**Released:** 2026-09-24 · **Channel:** stable · **Critical:** no

Turkish: [2.2.4-tr.md](2.2.4-tr.md)

A zip installer, a designed mail and DNS homepage, a visual spam score, and appearance controls for logo, colours, and layout. The updates screen can check for a new release on demand.

## What's new

**Check for updates.** The updates screen has a button that asks the release feed immediately, instead of waiting out the stored result.

**Appearance.** AACP → Appearance → General appearance sets the logo, favicon, and share image, the theme colours, logo height and width, site width, and navbar height.

**Mail and DNS homepage.** The public tools open on a designed hero with search, featured tools, and the site logo. SMTP tester signs in with the credentials you type and does not send mail or store the password. WHOIS falls back to RDAP when port 43 is blocked.

**Spam score.** The result is a scored dial with advice. Daily use is counted by IP, and the remaining allowance is shown. Sharing to the forum puts the result in the message body. Subjects stored as MIME encoded words are decoded.

**Installer.** A fresh zip install asks for the database and the first admin, marks that admin's e-mail verified, and leaves one blog post and one forum message. Roadmap, showcase, and the other optional modules stay off until you turn them on.

## Upgrade notes

After the files land, empty `cp-core/var/cache/prod/` (leave the folder). The new appearance setting is invisible until that cache is rebuilt.

## Known limits

The navbar height set in Appearance can be overridden by the theme's mobile rule. Guest and member daily limits differ, but the counter is the visitor's IP.
