# CPalius CMF 2.2.22

**Released:** 2026-09-25 · **Channel:** stable · **Critical:** no

Turkish: [2.2.22-tr.md](2.2.22-tr.md)

Design follow-up to 2.2.21's Security Center and VisitorStats work, based on direct feedback after that release.

## Security Center: threats and findings as two tabs

The live-threats table added in 2.2.21 sat as its own card below the audit-findings card, with a details column showing raw JSON that made rows uneven. Both are now one card with two tabs — Threats first (the reason an operator opens this page), Findings second — and the details column is gone from the table (the feed still shows time, severity, IP, user, event and score). The security posture card at the top is untouched.

## VisitorStats: two bar charts instead of one table

The admin page's daily-history table is now two CSS bar charts, built from the same data that was already there — no new tables, no new columns:

- **Daily**: the last 31 days, one bar per day, side by side.
- **Monthly**: the last 12 months, one bar per month, summed from the daily rows.

Hovering a bar shows its exact totals. A day or month with zero visits still gets its own (empty) bar rather than being skipped, so the chart reads correctly left to right.

## Upgrade notes

No schema changes. No manual steps.
