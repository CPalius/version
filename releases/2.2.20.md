# CPalius CMF 2.2.20

**Released:** 2026-09-25 · **Channel:** stable · **Critical:** no

Turkish: [2.2.20-tr.md](2.2.20-tr.md)

Two independent changes: telemetry and visitor statistics are now structurally separate, and a forum navigation block moved to a better spot.

## Telemetry and visitor statistics no longer share a table

They used to: security threat events and public page views both logged into `cp_system_telemetry_logs`, distinguished only by an `event_type` column the read side respected and the "clear logs" action didn't — clearing telemetry wiped visitor history with it. Page views also logged a full row per hit, which is most of a busy site's traffic.

Page views are now counted, not logged: three small new tables (one row per day, one row per hour, one row per distinct IP per day, all pruned automatically) replace the per-hit row entirely. Security events still log a full row each, in `cp_system_telemetry_logs`, untouched by anything visitor-related — the two can no longer collide, because they no longer share storage.

The visitor-mode dashboard keeps today's page-view and unique-visitor totals and its 24-hour trend chart; the per-row live feed table in that mode is gone, since there's no longer a row-per-visit to show. Security mode is unaffected.

## Forum: unread/drafts/topics moved to the board footer

The "Unread / My Drafts / My Topics / Messages / Mark all read" row used to sit at the top of the board, the topic list, and "My Topics" — now it sits at the bottom, directly above the statistics bar, restyled to match it instead of standing out as a differently-styled widget.

## Upgrade notes

One schema change: three new tables for visitor counting (`cp_visitor_daily_stats`, `cp_visitor_hourly_stats`, `cp_visitor_daily_seen_ips`), applied automatically by the update's migration step. No manual action needed.
