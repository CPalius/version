# CPalius CMF 2.2.6

**Released:** 2026-09-24 · **Channel:** stable · **Critical:** no

Turkish: [2.2.6-tr.md](2.2.6-tr.md)

An update was replacing the site's module list with the list shipped in the package, so modules an operator had switched off came back on.

## What's fixed

**Module switches stay put.** The package still updates every module's code. It no longer writes `cp-core/config/active_modules.php`. An update started by 2.2.5 puts the previous list back on the first request after the files land.

## Upgrade notes

Switch off the modules you do not want, then update. The backup taken at the start of the update is the list that is restored. Modules you deleted as folders can reappear on disk because they ship in the package; they stay off.
