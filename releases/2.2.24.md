# CPalius CMF 2.2.24

**Released:** 2026-09-25 · **Channel:** stable · **Critical:** no

Turkish: [2.2.24-tr.md](2.2.24-tr.md)

Visual redesign of the VisitorStats admin page's two charts. No data or schema changes.

## Daily traffic chart becomes a two-series line/area chart

The 31-day view was plain CSS bars. It is now a smooth line/area chart — built with Chart.js, the same library already powering the AACP dashboard's own trend chart — showing two series together (total visits and unique visitors) with a small legend, so the two are easy to compare day over day.

## Monthly chart becomes a bar chart

The 12-month view moves from CSS bars to a Chart.js bar chart, matching the daily chart's visual language.

## Upgrade notes

No schema changes. No manual steps. Chart.js is already bundled with CPalius core; nothing new to install.
