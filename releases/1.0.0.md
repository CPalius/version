# CPalius CMF 1.0.0

**Yayın tarihi:** 2026-09-14 · **Kanal:** stable · **Kritik:** hayır

İlk kararlı sürüm.

## Gereksinimler

| Bileşen | Gereken |
|---|---|
| PHP | 8.4+ |
| Eklentiler | `ctype`, `fileinfo`, `iconv`, `pdo_mysql`, `mbstring`, `openssl`, `gd` veya `imagick` |
| Veritabanı | MySQL 8.0+ / MariaDB 10.6+ |
| Üretim önbelleği | Redis (uygulama önbelleği + oturumlar), Memcached (fragment önbelleği) |

## Çekirdek

- Modül sistemi: `module.json` manifesti, kurulum betiği, yetenek (capability) kaydı, katkı (contribution) bildirimi
- Rol ve yetenek tabanlı yetkilendirme, Symfony Voter entegrasyonu
- Bildirim altyapısı: tip kaydı, kanal soyutlaması, kullanıcı tercihleri
- Global arama: modüllerin sağlayıcı (provider) kaydıyla katıldığı tek arama yüzeyi
- Cron: öznitelik tabanlı görev bildirimi (`#[CpCronJob]`), sanal ve gerçek crontab desteği
- Kuyruk: Messenger tabanlı asenkron iş altyapısı
- Güncelleme kancaları: sürüm etiketli, bir kez çalışan, defter (ledger) ile takip edilen veri taşımaları
- Yedekleme, denetim günlüğü, performans izleme, origin HTML önbelleği
- Çok dilli içerik ve arayüz; veritabanı üzerinden çeviri yönetimi
- AACP yönetim paneli: kullanıcı, rol, modül, tema, ayar, güvenlik merkezi, kurtarma konsolu
- `cp:doctor` — migration durumu, modüller, yetenekler, çeviriler, ortam ve güvenlik duruşunu denetleyen tanılama komutu

## Modüller

| Modül | Kapsam |
|---|---|
| **Forum** | 3 seviye bölüm hiyerarşisi, konu/mesaj, anket, ek dosya, ön ek, rütbe, itibar, taslak, konu bölme/birleştirme, satır içi moderasyon, ban/susturma, moderasyon günlüğü, bölüm bazlı izin matrisi |
| **Blog** | Yazı, kategori, yorum, portal blokları |
| **Pages** | Statik sayfalar |
| **Media** | Varlık yönetimi, görsel işleme, MIME izin listesi |
| **Menu** | Menü yapılandırma |
| **Seo** | JSON-LD şema grafiği, kaynak bazlı sitemap, robots yönetimi, başlık biçimlendirme |
| **Roadmap** | Yol haritası girdileri, portal ve arama entegrasyonu |
| **Whitepaper** | Ağaç yapılı belge yayını |
| **Widget** | Yan sütun bileşenleri |
| **Importer** | WordPress (WXR), Joomla, MyBB, XenForo ve CSV içe aktarımı; BBCode dönüştürücü; sayfalı, kesintiye dayanıklı aktarım |

## Güvenlik

- Yükleme dizini sertleştirmesi (beş katmanlı `.htaccess`: erişim reddi, handler kaldırma, motor kapatma, CGI kapatma, CSP)
- CSRF koruması, captcha, flood (hız) sınırlama
- İki faktörlü kimlik doğrulama
- Denetim günlüğü ve güvenlik merkezi
- Veritabanı veya güvenlik duvarı çöktüğünde erişim sağlayan kurtarma konsolu (`AACP_RECOVERY_TOKEN`)

## Bilinen kısıtlar

- Üretim modu Redis ve Memcached gerektirir; dosya sistemine düşen bir yedek yol yalnızca `dev` ve `test` ortamlarında tanımlıdır.
- Forum araması `LIKE` tabanlıdır; büyük veri kümelerinde tam metin indeksi önerilir.
- Özel mesajlaşma (PM) bu sürümde yoktur.
