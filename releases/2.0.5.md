# CPalius CMF 2.0.5

**Released:** 2026-09-18 · **Channel:** stable · **Critical:** no · **Type:** patch

Turkish: [2.0.5-tr.md](2.0.5-tr.md)

A small follow-up to 2.0.4, fixing what turned up in use and finishing two
things that were left half-done.

## Fixes

**The @ mention suggestions no longer show a full-size photo.** The avatar in
the autocomplete flyout had no size of its own, so a member with a large profile
picture filled the screen with it while you were typing their name.

**"Mark all as read" for private messages.** Clearing the red badge meant
opening every unread conversation one at a time. There is now a single action in
the message flyout, and both it and the notifications one work without reloading
the page — the menu stays open and the counts drop immediately.

**"My topics" is paginated.** The list stopped at 50 topics with no way to reach
the ones behind them. It now pages like any other topic list, and how many it
shows per page comes from Studio → Forum → Settings, the same setting the board
list uses. The unread list follows that setting too.

## What's new

**Who is online, broken down.** The board footer used to show a single number,
which on most forums is mostly crawlers and tells you nothing. It now shows four
counts with their own icons — members, guests, search engines and bots — and the
online page opens with the same four.

Search engines are kept apart from other bots on purpose: a search engine
indexing your board is traffic you want, while scrapers, monitors and AI
crawlers may be traffic you would rather reduce. Counting them together hides
exactly the difference worth seeing.

Guests, search engines and bots are counted but never listed. An anonymous
session is an IP address and a user-agent — not something to publish on a page.

## Upgrade notes

**A new column is added for you.** The who-is-online breakdown needs to record
what each visitor was, which is a column on the presence table. A patch cannot
run migrations, so the column is added automatically on first use. If your
database user is not allowed to change tables, the board keeps counting members
and guests exactly as it did before and the other two counts stay at zero.

**Visitors are classified from this release onwards.** Rows already in the table
when the update lands are counted as guests. They expire within minutes of
normal browsing, so the breakdown is accurate almost immediately.

**If you deploy by FTP,** clear `cp-core/var/cache/prod/` after uploading —
leave the folder, empty its contents. Unlike 2.0.4 this release changes no
compiled assets, so `public/assets/` does not need re-uploading.
