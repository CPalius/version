# CPalius CMF 2.1.3

**Released:** 2026-09-22 · **Channel:** stable · **Critical:** no

Turkish: [2.1.3-tr.md](2.1.3-tr.md)

This release is about writing once and reading in every language, and about
the inbox staying quiet once you have already seen the alert.

## What's new

**An independent Ai module.** Forum topics, blog posts and pages can be
translated on create and on edit. The module lives under `cp-content/modules/Ai/`
and talks to the rest of the system through events and form fields — Core does
not import it. The API key is a Studio setting, never a file in the package.

**Studio post list without a reload.** Language tabs stay on one row with a
compact search box. Typing searches titles and slugs in every locale and labels
the language on each hit. Author, date, category, type and status sit behind a
Filters button so the page does not shove sideways. Publish and delete also
stay on the list.

**Live search on the website.** The header search and the `/ara` page show
grouped hits as you type. Enter still opens the full results page.

**The profile inbox keeps only unread items.** Notifications and messages that
have been marked read leave the flyout. The full inbox and messages pages still
hold the history.

## Upgrade notes

**Forum topics gain a translation group column.** Dual-gate SQL ships in
`cp-content/modules/Forum/Resources/migrations/`. After the panel update, open
Studio → Forum once so the installer can finish.

**Ai is on in this package.** Existing sites that keep extra modules in
`active_modules.php` should confirm the file still lists them after the
update, then enable Ai from AACP → Modules if it is not already there. Paste
the provider key in Studio → Ai. An empty save keeps the current key.

**If you deploy by FTP rather than through the panel,** clear
`cp-core/var/cache/prod/` after uploading — leave the folder, empty its
contents. Upload `public/assets/` as well.

## Known limits

**Ai does not translate inside Core business logic.** Forum, Blog and Pages
only emit events and add a checkbox. Turning the module off leaves those
forms as they were.

**Live search looks at title and slug, not the full body.** The full `/ara`
page still aggregates module providers for a deeper pass.
